# Hey, I'm Rishi 👋

Engineering student by day, world-builder by night.

I'm a CS undergrad at MIT AOE, Pune — tinkering at the intersection of
systems, games, and the web. I build things that feel alive: from
Discord bots and Moodle-integrated student tools to dark-fantasy skill
trees and graph visualizers with Dijkstra running under the hood.

Currently obsessed with:
- 🎮 Game dev in **Godot 4** (GDScript + component-based architecture)
- 🐧 Living inside **CachyOS** and making Linux do my bidding
- 🤖 Building tools that make student life less chaotic

When I'm not coding, I'm probably designing mechanics for a story
that's way too ambitious for one person.
